# 同源符号扩展整合说明

## 来源与范围

本次整合基于原 GitHub 仓库，以及本地 `BIA_TIM_同源符号修正版_12组图_20261022` 成果包。目录日期为归档名称；其配置与生成记录使用种子 `20261020`，不把目录日期当作运行日期。

对应源码位于已有 `isac_rebuild` 项目，主入口为 `run_shared_source.py`。成果包未携带生成源码、`manifest.json` 和 `raw/`；本次从该源码项目的 `results_shared_source` 补齐。导入前逐文件比对成果包与源结果目录，并核对历史 manifest 中的数值及绘图源码 SHA256。具体文件哈希记录在 `extensions/shared_source/import_provenance.json`。

原 MATLAB 文件保留在仓库根目录。当前有效的 Python 扩展独立放在 `extensions/shared_source`，只引入其运行依赖和两份现有测试文件。`fixed_waveforms.py` 依赖 `benchmarks.py`，所以一并保留该模块；这不意味着启用旧版基线实验。

未导入旧的 18 图、旧联合 tradeoff 或按性能筛选的结果包。它们使用过不同的基线独立符号数或通信接收机，不适合作为本次同源符号比较的主结果。此处整理已有结果，没有新增研究结论。

## 可复现性的层次

1. `reproduce.py verify`：重新从保存的 NPZ 样本和 CSV 检查统计量、资源约束、图表数据、有限星座速率上限和历史源码哈希。
2. `reproduce.py plot`：复制归档后重新生成图，不消耗新的随机样本。PDF 时间戳、字体或不同 Matplotlib 版本可能导致文件字节不同。
3. `reproduce.py full`：固定配置重新运行 Monte Carlo，再验证新输出。运行环境另存为 `run_environment.json`；不同数值库/BLAS 版本可能造成浮点差异，不能只用 PDF 或 NPZ 文件哈希判定科学结果是否复现。
4. `reproduce.py compare`：对新运行与归档的通信/感知主表逐行比较均值及样本数。发现差异返回退出码 1。内部验证通过不代表历史曲线已精确复现。

本次完整重跑暴露了原 SIC 实现的数值敏感性：通信均值全部匹配，部分 SIC 感知统计不匹配。初始 LS 残差对应的一部分软判决接近机器精度的零，直接按正负号硬判决会放大数值环境的差别。`tools/audit_sic_numerics.py` 可复查这个现象。当前整合保留原科学算法及归档；没有通过修改种子、放宽统计对比容差或覆写归档来掩盖差异。修正平局判决策略需要单独建立经审查的新结果版本。

原有数值和绘图源码保持字节一致，以使历史源码哈希继续有效。`.gitattributes` 对导入目录关闭文本换行转换，避免 Windows/Linux 检出改变哈希。原 manifest 没有覆盖所有传递依赖；新增导入记录补充记录了所有导入源码的哈希，不把原 manifest 的覆盖范围夸大为完整供应链验证。

验证器增加了默认只读行为，只有显式 `--write-report` 才写 `verification.json`，显式 `--render-pdf` 才保存 PDF 页面预览。数值判定规则保留。统一入口会拒绝 Python 优化模式，因为原检查代码使用 `assert`。

归档的 `verification.json` 是历史检查记录；本次维护验证记录另见 `docs/VALIDATION.md`，二者不混用。

## 后续维护

- 添加新实验时复制配置，并使用新的输出目录；不要覆写 `reference/`。
- 若修改核心数值模型或绘图代码，应生成新结果，并保留旧归档对应的源码版本；原有哈希检查会主动报告差异。
- 当前 12 图绘图代码依赖固定的四类波形和部分固定 SNR 切片。新增网格、场景或接收机需要同步扩展绘图及验证器。
- 接入 CSI 误差、时变信道、硬件失配或新波形优化时，继续保持数据、能量、时间和接收机信息假设的可比性。
- 当前仓库未声明软件许可证，本次整合不替作者指定新的许可证。
